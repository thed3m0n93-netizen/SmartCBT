Akar masalahnya **bukan** pada upload ke disk (berkas selalu tersimpan) melainkan pada **bentuk respons yang tidak cocok**: `src/lib/server/storage.ts` membalas `json(res, { file: inserted })` — baris metadata dibungkus dalam `file` — sementara `uploadFile()` di `src/lib/api.ts` mengetik respons itu sebagai `UploadRow` **tanpa melepas pembungkusnya**, sehingga `result.path` selalu `undefined`; di halaman, `const url = result.path ?? ""` jadi `""`, lalu `persistBranding(key, "")` **menimpa pengaturan dengan string kosong**. Hasilnya: unggahan "berhasil" (tidak ada error, pesan sukses tampil), tetapi logo/background tidak pernah terganti. Perbaikan & penambahan:
>   - `src/lib/api.ts` — `uploadFile()` melepas pembungkus `{ file }` secara defensif (`res.file ?? res`) dan **melempar error** bila server tidak mengembalikan `path` sehingga kegagalan tidak lagi senyap; ditambahkan helper `resolveAssetUrl()` (URL `/uploads/...` yang tersimpan relatif dapat dipakai `<img src>` meski API berada di origin berbeda), `isCrossOriginAsset()`, serta tipe `SchoolSettings.school_favicon`.
>   - `src/lib/server/settings.ts` — key `school_favicon` didaftarkan di `DEFAULT_SETTINGS`, dan ditambahkan **dua endpoint khusus branding**: `POST /api/settings/branding` (validasi per-slot: ekstensi + MIME + batas ukuran; menulis berkas ke `public/uploads`, menyimpan URL ke key settings yang tepat, mencatat metadata ke tabel `uploads`, dan **menghapus berkas lama**) serta `POST /api/settings/branding/remove` (mengosongkan key + menghapus berkasnya). Karena penyimpanan berkas dan penulisan settings terjadi dalam **satu request**, nilai tidak mungkin lagi hilang di antara dua panggilan; hanya `super_admin`/`admin` yang diizinkan (anonim → 401).
>   - `src/pages/admin/SettingsPage.tsx` — handler upload memakai endpoint baru, memvalidasi berdasarkan **ekstensi** (bukan hanya `file.type`, karena `.ico` sering dilaporkan MIME kosong) dan menampilkan pesan error server apa adanya (dulu error di-swallow tanpa jejak) di samping Notice global; pratinjau logo/background memakai `resolveAssetUrl()`.
>   - **Fitur baru — favicon ikon kustom sekolah**: slot unggah **Favicon** di panel Branding (format `.ico`, `.png`, `.svg`, `.jpg`, `.webp`, maks 2 MB, saran 32×32 atau 512×512) dengan pratinjau, catatan origin lintas-domain, dan tombol Hapus.
